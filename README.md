# 🩸 RedHope – Blood Donation Platform

RedHope is a modern web-based blood donation platform designed to connect donors, recipients, and administrators in a fast, secure, and user-friendly way. The application allows users to manage profiles, request blood donations, and maintain an organized donation system.

---

## 🚀 Live Demo
https://serene-beijinho-c5edf4.netlify.app/



---

## 📌 Key Features

### 👤 User Features
- Firebase-based authentication
- User profile creation and update
- Profile image upload
- Blood group, district, and upazila management
- Secure login and logout
- Toast notifications for user actions

### 🩸 Blood Donation System
- Blood group-based donor management
- Location-based donor information
- Partial profile updates using PATCH API
- Responsive and clean UI

### 🛠 Admin & Role-Based Features
- Role-based access (Admin / Donor)
- User status management
- Scalable and maintainable structure

### 🎨 UI & UX
- Fully responsive design
- Smooth animations using AOS
- Modern alert dialogs
- Reusable and modular components
